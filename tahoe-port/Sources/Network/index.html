AirportItlwm on macOS 26

TAHOE

Built on the upstream itlwm project, tuned for macOS Tahoe 26.x (x86_64). AirportItlwm drives Intel cards through the native Wi-Fi interface — scanning, connecting, network switching and private Wi-Fi addresses behave as first-party.

SCANNING CONNECTING NETWORK SWITCHING PRIVATE WI-FI ADDR
BOOT-ARG itlwm_he=1

Wi-Fi 6 (802.11ax / HE) is disabled by default. Add itlwm_he=1 to enable it on supported adapters.

Device support follows the upstream hardware table — Tahoe compatibility still requires validation on each adapter.

SUPPORT MATRIX TAHOE 26.X
  • Native Wi-Fi interface
  • Scanning & connecting
  • Network switching
  • Private Wi-Fi addresses
  • WPA2-Personal
  • WPA2/WPA3 transition · optional PMF
  • WPA3-only networks
  • Mandatory PMF
  • AWDL / AirDrop
  • MLO
HE / WI-FI 6 — OFF BY DEFAULT · OPT-IN VIA BOOT-ARG

Build from source

XCODEBUILD

Build it yourself. Install Xcode and Python 3, check out MacKernelSDK at commit 3f75008 inside MacKernelSDK/, then compile the Tahoe scheme:

visitor@mac — zsh · AirportItlwm-Tahoe
# 1 · prerequisites — Xcode & Python 3
$ xcode-select --install
# 2 · MacKernelSDK @ 3f750085caa17ec3a7880f11c11bf4f48cd6a164
$ git clone https://github.com/acidanthera/MacKernelSDK.git
$ git -C MacKernelSDK checkout 3f750085caa17ec3a7880f11c11bf4f48cd6a164
# 3 · build — AirportItlwm · Tahoe
$ xcodebuild -project itlwm.xcodeproj -scheme AirportItlwm-Tahoe \
  -configuration Release ARCHS=x86_64 \
  CODE_SIGNING_ALLOWED=NO build
$
